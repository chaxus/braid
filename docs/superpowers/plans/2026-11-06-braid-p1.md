# Braid P1 Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox syntax.

**Goal:** Ship a runnable macOS NSH app with a menu-panel connection UI and a mock TUN state machine.

**Architecture:** NSH renders the panel; a small Rust (or TSX) store owns connection state; no sing-box process yet.

**Tech Stack:** NSH, Rust (preferred) or mixed template, macOS 14+

**Spec:** [docs/SPEC.md](../../SPEC.md)

## Global Constraints

- MIT; copyright `chaxus`
- No production credentials in the tree
- English UI strings in code for v0.1 (zh copy can wait)
- Primary accent: one neutral brand color; follow system light/dark

## Review Focus

- Accidental secret commit
- Claiming “Connected” when only mocked
- Blocking UI thread on fake delays (use async/timer)
- Menu-panel too dense (Clash-like)
- Missing Failed / permission states
